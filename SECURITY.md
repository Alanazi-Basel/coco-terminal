# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting for this repository. Include the
affected version, reproduction steps, impact, and any suggested mitigation.
You should receive an acknowledgement within seven days.

## Sensitive local data

Coco Terminal can handle shell history, SSH host details, key paths, and
terminal session state. Reports and reproductions must use synthetic data and
must not include real credentials, private keys, tokens, or terminal captures.
